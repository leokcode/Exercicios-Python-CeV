# Exercícios Python - Curso em Vídeo

Resolução dos exercícios do curso de Python 3 do canal Curso em Vídeo (prof. Gustavo Guanabara), do Mundo 1 ao Mundo 3.

## Conteúdo praticado

- Mundo 1 - Fundamentos: variáveis, tipos de dados, operações, módulos e condições simples
- Mundo 2 - Estruturas de controle: condições aninhadas, for e while
- Mundo 3 - Estruturas compostas: tuplas, listas, dicionários, funções, modularização e tratamento de erros

## Como executar

1. Tenha o Python 3 instalado
2. Clone o repositório: `git clone https://github.com/leokcode/Exercicios-Python-CeV.git`
3. Execute um exercício: `python nome_do_arquivo.py`
